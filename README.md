# nixos-config — tblpt (Dell XPS 15 7590)

The whole system configuration for one laptop: NixOS 26.05 with KDE Plasma 6,
LUKS-encrypted btrfs, hybrid Intel UHD 630 + NVIDIA GTX 1650 graphics.

This machine gets used a few times a week or not for months. The commands below
are written down because they are the ones that get forgotten in between.

## The five commands

```sh
# Rebuild after editing anything in this repo
sudo nixos-rebuild switch --flake ~/nixos-config#tblpt

# Apply at next boot instead of immediately — the right choice for kernel and
# graphics driver changes
sudo nixos-rebuild boot --flake ~/nixos-config#tblpt && systemctl reboot

# Undo the last rebuild (older generations are also in the boot menu)
sudo nixos-rebuild switch --rollback

# Update all inputs (nixpkgs, nixos-hardware), then rebuild as above.
# Commit the changed flake.lock — that file is the reproducibility.
nix flake update --flake ~/nixos-config

# Reclaim disk space: deletes every generation but the current one
sudo nix-collect-garbage -d
```

## How to add a package

Add it to `environment.systemPackages` in `hosts/tblpt/default.nix`, then
rebuild. Search for the attribute name first:

```sh
nix search nixpkgs firefox
```

Everything installed on this machine lives in that one list — no `nix-env`, no
per-user package sets — so the list answers "what is on this laptop?" by itself.
Packages are added one at a time, one rebuild and one commit each, so a bad
change is easy to find and revert.

## Layout

| Path | What it is |
|---|---|
| `flake.nix` | Inputs (nixpkgs 26.05, nixos-hardware) and the `tblpt` system output |
| `flake.lock` | Pinned input revisions. Committed on purpose — without it "same repo" does not mean "same system" |
| `hosts/tblpt/default.nix` | Hostname, user, locale, desktop, package list |
| `hosts/tblpt/hardware-configuration.nix` | Generated by the installer; filesystems and LUKS device. Not hand-edited |
| `modules/` | Feature modules, split out as the config grows |
| `docs/` | The migration kit: hardware notes, old software inventory, easyroam/eduVPN findings |

## A note on what is not here

This repo is public. It contains no credentials, no certificates, no university
account name, no internal hostnames or IP addresses, and no WiFi history. Those
details were kept in a local, gitignored file instead — see `.gitignore` and
`docs/HANDOVER.md` §3.

If an easyroam PKCS#12 client certificate ever gets added for the declarative
route, it must be encrypted with sops-nix or agenix first. It is a credential,
not a config file.
